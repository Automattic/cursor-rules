# WordPress Cursor Rules

This repository is meant to contain a smorgasbord of cursor rules to be used in WordPress related projects.
We hope to organize them in a modular way where they can be just dropped into your project and serve as a base to later extend.

## Standard files


### Official WP Coding standards

These are compressed versions of https://developer.wordpress.org/coding-standards/wordpress-coding-standards
